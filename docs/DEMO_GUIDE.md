# Reproducible local demonstration

Use the documented loopback Docker/PostgreSQL17 profile and your own bootstrapped administrator. No default password exists. Setup/model/data commands are in [REPRODUCIBILITY.md](REPRODUCIBILITY.md); generated secrets and public research recordings stay outside Git. The prior team-owned [DEMO_SCRIPT.md](DEMO_SCRIPT.md) is preserved as historical material.

1. Start frontend/backend/PostgreSQL and verify health. Sign in and open Cameras & Zones. Register the **recorded research video**, enable fall/camera-health and configure explicit RGB crop `0.5,0,1,1` only for composite URFall footage. Use the actual camera UUID in the device allowlist. This camera is a replay, not a physical installation.
2. Run the normal worker against a known demonstrated sample such as fall07. Default rules are not broadly reliable; choosing a demonstration sample is disclosed and is not an evaluation. Alternatively run the explicitly opt-in learned checkpoint against fall27 using its SHA and matching pose model; disclose its unacceptable ten-negative false alerts on the fresh test.
3. Open the generated incident notification. Play preserved evidence; inspect track ID, trigger signals, model/checkpoint provenance and uncertainty. Local CV analysis is not scripted Demo AI or an LLM observation.
4. Review cited stored SOP passages. Confirm or dismiss based on evidence. An authorized manager/administrator selects and approves permitted actions. Execute **simulation only**, inspect audit entries and download the PDF. No external emergency message or physical machinery action occurs.
5. Open PPE Compliance. Inspect eight disabled class gates and clearly labeled appearance AP, not compliance accuracy. Administrators can preview requirements for a camera and explicit activity/role/local time; leaving context blank keeps conditional rules unknown. Requirements may be configured without enabling a detector.
6. For actual PPE model inference, run `python -m safetylens_detector.ppe_image` with the acquired official ONNX manifest and a public SH17 image. It emits actual appearance boxes and per-person assessments; unknown safety ratings/visibility remain unknown. This offline result does not generate a claimed validated PPE incident stream. No wearer accuracy is available.

If services fail, show the error and recover or disclose precomputed artifacts. Do not replace real inference with synthetic output without labeling it. The default browser fixture is synthetic unless actual-model environment variables are provided.

Automation: `scripts/verify_compose.py` completes actual-model response/report and controlled recovery; `scripts/verify_camera_load.py` exercises four repeated recorded workers and local MJPEG failure; `scripts/verify_fresh_postgres.py` migrates a new verification database without touching the existing DB. These probes create private QA records on a dedicated test installation. They are not commands for an operational site.
